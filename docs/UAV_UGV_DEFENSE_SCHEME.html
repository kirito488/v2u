1. 目标与输出

每帧并行得到三路检测：

  • Ego：车载 PointPillar（本地点云，可信锚点）
  • UAV：无人机 PointPillar（可被攻击）
  • Init：中间融合 AttFuse（等权融合特征再检测）

以 Ego 为空间锚做门控与证据更新；已确认目标进信任池，未确认目标进Tentative 缓冲。最终接受集（报告用 AP / ASR）为：

\[ \hat{Y} = \{\text{pool 输出}\} \cup \{\text{本帧 Certain}\} \cup \{\text{缓冲 CONFIRM}\} \cup \{\text{池 ATTACK coast}\} \]

池 ATTACK 的 KF coast 框（已确认目标被抹除时的暂存）计入接受集 （ACCEPTED_STATES 含 "attack"）。缓冲侧的 ATTACK 只打标、不进 \(\hat{Y}\)。 \(\hat{Y}\) 是后续 AP / ASR 的主要依据。

核心思想（ROBOSAC）：协同应与单车共识而非分歧。Ambiguous 用 Dual（UAV∧Init）升 Certain；Tentative 用 Ego 证据贝叶斯观察；池内丢失且 UAV 本应可见则 ATTACK coast。

2. 检测表示与感知置信度 \(C\)

2.1 检测元组

每个检测：框 \(\mathbf{B}=(x,y,z,l,w,h,\theta)\)、存在概率 \(P\)、感知置信度 \(C\)。检出标志

\[ D = \mathbf{1}\{P \ge \theta_P\} \quad\text{且与当前物体匈牙利关联成功} \]

\(\theta_P\) / score_thres（当前批 0.3；代码默认 THETA_P=0.5） 分度校准 — 跑批时 CLI 设 0.3，同时把防御内部的 theta_p 设为同一值。

检测质量：

\[ Q = P \cdot C \]

\(P\) 来自检测头分类分；\(C\) 只由该源点云决定，不回填分类分。

2.2 \(C\) 的完整计算（当前：\(C_{\mathrm{abs}}\cdot V\)）

设计目标：回答「这个传感器是否把物体看清楚了？」——绝对点数 × 视线是否被挡。 相对点云项 \(C_n=n/n_{\mathrm{exp}}\) 已弃用（USE_CN=False），由 polar 可见度 \(V\) 直接替换：

\[ C = C_{\mathrm{abs}} \cdot V \] \[ C_{\mathrm{abs}} = \mathrm{clip}\!\left(\frac{n}{n_{\mathrm{ref}}},\,0,\,1\right),\qquad V = \frac{\#\{\text{自由射线}\}}{N_{\mathrm{ray}}} \quad (N_{\mathrm{ray}}=75) \]

门控用全量 \(Q=P\cdot C=P\cdot C_{\mathrm{abs}}\cdot V\)；Tentative 正证据用 \(Q_{\mathrm{buf}}=P\cdot C_{\mathrm{abs}}\)（§6.1），几何 \(v\) 仍单独进 \(w(v)/e_-\)，避免 \(V\) 乘两次。

2.2.1 框内点数 \(n\)

  • 检测框先从 OpenCOOD 的 bottom-center 抬到几何中心：\(z \leftarrow z + h/2\)。
  • 在该源 LiDAR 坐标系下统计落入框内（含 pad）的点数 \(n\)。

Ego pad（0.25 m）· UAV pad（0.5 m） ablation — UAV 顶视框略松；可消融 pad 对 \(C\) / ASR 的影响。

2.2.2 绝对项 \(C_{\mathrm{abs}}\)

\(n_{\mathrm{ref}}\) 取约 25 m 处点云数的低分位量级，避免与 \(V\) 相乘后 \(C\) 整体塌缩：

\(n_{\mathrm{ref}}^{\mathrm{ego}}\)（200）· \(n_{\mathrm{ref}}^{\mathrm{uav}}\)（200） 分度校准 — 来自 clean 探测（≈25 m ego p10–p25）；旧 clear 近场中位 ~2029 过严，已不用。

2.2.3 可见度 \(V\)（替换旧 \(C_n\)）

与 §6.1.1 同一套 polar 深度：对该源点云建图，在查询 OBB 上采 5×5×3=75 射线，\(V=\) 穿透比例。 无深度时回退 \(V=1\)（\(C\) 退化为 \(C_{\mathrm{abs}}\)）。旧 \(n_{\mathrm{exp}}/A_{\mathrm{ref}}/r_0\) 路径仅保留为 use_cn=True 消融。

2.2.4 三源各自算 \(C\)；Init 取平均

  • Ego / UAV：各自用自己的点云算 \(C_{\mathrm{abs}}\) 与 \(V\)，再 \(C=C_{\mathrm{abs}}V\)。
  • Init 融合特征若直接计点会被攻击抬高假 \(C\)，故
\[ C_{\mathrm{init}} = \tfrac{1}{2}\big(C_{\mathrm{ego}} + C_{\mathrm{uav}}\big),\qquad V_{\mathrm{init}} = \tfrac{1}{2}\big(V_{\mathrm{ego}} + V_{\mathrm{uav}}\big) \]

实现：见 confidence.confidences_for_boxes / three_source._c_*。

2.3 经验结论：高 \(V\) 是 Ego 检出的强必要条件

探针（clean，连续 200 帧，probe_cabs_v_75rays_clean_200f，75 射线，\(n_{\mathrm{ref}}=200\)）：
  • 已过阈的 Ego 检出（\(P\ge 0.3\)）中，\(V\) 中位 \(\approx 1\)、均值 \(\approx 0.95\)；\(V\ge 0.75\) 占绝大多数，且这些框的 TP 率 \(\approx 99.7\%\)。
  • 对场上 GT：\(V<0.75\) 时 Ego 几乎检不出；\(V=1\) 时 recall \(\approx 83\%\)；仅 \(V\ge 0.75\) 时 recall \(\approx 47\%\)（高 \(V\) 必要但不充分）。
含义：车端「能稳定检出」高度依赖接近全可见（\(V\to 1\)）。 这可作为后续 Tentative 加分 的参考点（例如：在已有 \(e_+=\kappa_+\psi(Q)w(v)\) 之外，对 \(V\approx 1\) 且 Ego 命中的 watch 再给一小项清晰度奖励；或把 \(\psi\) 的参考从 \(Q_l\) 与高 \(V\) 分位联动）。 分度校准 / ablation — 尚未改证据公式；先记入方案，再单独设计加分项，避免与 \(w(v)\)（遮挡时反而加大正证据）打架。

3. 同帧关联

Ego–UAV、Ego–Init 做匈牙利匹配，代价 \(1-\mathrm{IoU}\)（BEV）。IoU 过阈才视为同一物体，得到

\[ D_{\mathrm{ego}},\, D_{\mathrm{uav}},\, D_{\mathrm{init}} \in \{0,1\} \]

\(\theta_{\mathrm{IoU}}\)（0.3，THETA_IOU） ablation； 距离门 \(\theta_d\)（4.0 m，THETA_DIST，备用） ablation。

跨帧一致性由池 / 缓冲的常速度 KF 承担，不做「整帧丢弃协作源」。

4. 空间门控

对以 Ego 为锚的物体，用 \(Q_{\mathrm{ego}}=P_{\mathrm{ego}}\cdot C_{\mathrm{ego}}\) 分三态：

状态条件处理
Certain \(D_{\mathrm{ego}}=1\) 且 \(Q_{\mathrm{ego}} \ge Q_h\) 采信 Ego 几何；可入池 UPDATE / BIRTH；本帧直接进接受集
Ambiguous \(D_{\mathrm{ego}}=1\) 且 \(Q_l \le Q_{\mathrm{ego}} < Q_h\) 看 Dual：UAV 与 Init 都命中 → Certain，否则 → Tentative
Tentative 其余（无 Ego，或 \(Q\) 过低，或 Dual 失败） 本帧不直接输出，进缓冲观察
\[ Q_h = 0.40,\qquad Q_l = 0.30 \quad\text{（显式标定；不再用 }\theta_P\cdot\mu\text{）} \]

代码常量：\(Q_h=\mathbf{0.40}\)、\(Q_l=\mathbf{0.30}\) 分度校准 — 2026-09-07 按 clean 200 帧、\(C=C_{\mathrm{abs}}V\)、\(n_{\mathrm{ref}}=200\)、\(P\ge 0.3\) 的 Ego \(Q=P\cdot C\) 分布重定 （约 Certain 61% / Ambiguous 25% / Tentative 14%）。 旧 \(\theta_P^{\mathrm{default}}\cdot\mu\)（0.35/0.25）在 \(C\approx 1\) 时 Certain 过密；若机械改成 \(\theta_P=0.3\cdot\mu\)（0.21/0.15）则 Ambiguous 几乎消失。 缓冲 \(\psi\) 的参考同为 \(Q_l\)（对 \(Q_{\mathrm{buf}}=P\cdot C_{\mathrm{abs}}\)）。

\[ \mathrm{Dual} = (D_{\mathrm{uav}}=1) \wedge (D_{\mathrm{init}}=1) \]

门控 / 池仍只用硬分轨（\(P\ge\theta_P\)）；缓冲对已有 watch 另开软 Ego 带：低分 Ego 只加正证据，不新建、不进 Certain。

\(\theta_{\mathrm{soft}}\)（0.05，THETA_SOFT） 锁定 — 软带 \([\theta_{\mathrm{soft}},\,\theta_P)\)。

5. 信任池

已确认轨维护常速度 KF（状态 \((x,y,v_x,v_y)\)）。每帧：预测 → Certain Ego 匹配 → 其余源 HOLD → 全 miss 再判 ATTACK / MISS。

动作含义
UPDATECertain Ego 命中 → KF 更新，框进 \(\hat{Y}\)
BIRTHCertain Ego 无匹配轨 → 新建
HOLD非 Certain 路径上 Ego / UAV / Init 任一命中 → 保留但不更新 KF
ATTACK三源皆 miss，且 UAV 本应看见 → KF coast 进 \(\hat{Y}\)
MISS / DROP三源 miss 且 UAV 不可见（或超龄）→ 短保留后丢弃

池保留龄 \(K\)（3，POOL_K） ablation。 BIRTH / CONFIRM 入池时，KF 速度用缓冲轨迹差分初始化（优先 ego 源 hist，否则 fuse/init；velocity_from_traj / birth_state(..., traj=)），避免静止先验。

5.1 UAV「本应看见」

  • 框须在 UAV FOV 内（uav_fov.box_in_uav_fov）；FOV 外只用 \(C_{\mathrm{uav}}\)；
  • FOV 内：把框 warp 到 UAV 系后，用 UAV 点云 polar 深度图算视线得分 \(V_{\mathrm{uav}}\)（见 §6.1.1）；
  • 或框内 UAV 点密度给出的 \(C_{\mathrm{uav}}\)；
  • 综合可见度
\[ u = \max(V_{\mathrm{uav}},\, C_{\mathrm{uav}}) \]

过阈则判 suppression（remove 攻击下的「本该看见却 miss」）。

\(v_{\min}\) / 攻击可见阈（0.25，V_MIN） ablation； 连续 miss 判 ATTACK 的龄 \(k_{\mathrm{atk}}\)（10，K_ATK） ablation。

用 UAV 视线而不是车端射线：Ego 漏检常因遮挡，车端可见度会系统性偏低。点云 remove 会压低密度，射线穿透仍可判 ATTACK。
池 ATTACK = 已确认目标被抹，coast 进输出； 缓冲 ATTACK = 仍不确定，只打标，不进 \(\hat{Y}\)。

6. Tentative 缓冲

观察中目标维护后验 \(\mathcal{P}\) 与 KF。初值以中性先验 \(0.5\) 为中心，按协作占比与 Ego 质量门控缩放；无全局信任分。

\[ \mathcal{P}_0 = \max\!\big(0.5 \cdot g_{\mathrm{uav}}(Q_{\mathrm{collab}}, Q_{\mathrm{ego}}) \cdot s(Q),\, P_{\min}\big) \] \[ g_{\mathrm{uav}} = \frac{Q_{\mathrm{collab}}}{Q_{\mathrm{ego}}+Q_{\mathrm{collab}}}\,\varphi(Q_{\mathrm{ego}}),\qquad \varphi(Q)=\sigma\!\left(\frac{Q_l-Q}{\tau}\right),\qquad s(Q)=\mathrm{clip}\!\left(\frac{Q}{Q_l},\,P_{\min},\,1\right) \]

\(P_{\min}\)（0.15） ablation； \(\tau\)（0.1） 锁定 sigmoid 温度。

6.1 证据（只看 Ego）

可见度 \(v\) 用车端 LiDAR polar 深度（缓冲问的是「车该不该看见」；见 §6.1.1）。 Tentative 正证据质量用 \(Q_{\mathrm{buf}}=P_{\mathrm{ego}}\cdot C_{\mathrm{abs}}\)（不含 \(V\)），避免与 \(w(v)\) 重复计遮挡； 门控 Certain/Ambiguous 仍用全量 \(Q=P\cdot C=P\cdot C_{\mathrm{abs}}\cdot V\)（§2）。 缓冲几何 \(v\)（\(w(v),\,e_-\)）保持原样、独立计算。

\begin{align} w(v) &= 1 + \sigma\!\left(\frac{0.5 - v}{\tau}\right) \in (1,2) \\ e_+ &= +\kappa_+\,\psi(Q_{\mathrm{buf}})\,w(v) \quad\text{（硬 / 软 Ego 命中；}Q_{\mathrm{buf}}=P\cdot C_{\mathrm{abs}}\text{）} \\ e_- &= -\kappa_-\,v \quad\text{（未命中 Ego，含仅有 UAV/Init）} \\ \psi(Q) &= \sigma\!\left(\frac{Q - Q_l}{\tau}\right) = 1-\varphi(Q) \end{align} \[ \mathrm{logit}(\mathcal{P}_t) = \mathrm{logit}(\mathcal{P}_{t-1}) + e \]

\(\psi(Q_{\mathrm{buf}})\) 随 \(P\cdot C_{\mathrm{abs}}\) 升高；开敞漏检（\(v\approx 1\)）重罚，遮挡漏检轻罚。UAV/Init 从不单独加正分。 后续若按 §2.3 做「高 \(V\) 清晰度加分」，应作为额外项设计，避免与 \(w(v)\)（低 \(v\) 时抬大正证据）直接冲突。

\(\kappa_+\)（1.4）· \(\kappa_-\)（1.0） ablation； \(v_0\)（0.5，与先验中点共用） 锁定。

6.1.1 可见度 \(V\)：点云 polar 深度（今日替换旧 box-ray）

旧实现：从原点向框打 BEV 射线，用其它检测框当遮挡物——曾因未传入 occluders 经常得到 \(V\equiv 1\)。
当前实现（occlusion.build_polar_depth / visibility_ratio_lidar）：

  1. 把本帧点云建成传感器系 polar 最小距离图（方位 0.5° × 俯仰 1°）；
  2. 在查询 OBB 上采密网格 5×5×3 = 75 个 3D 探针；
  3. 每条射线：若同方向深度图上有比目标近端面更近的回波 → 挡住；否则穿透；
  4. \(V =\) 穿透数 / 75。

检测框原点是底面中心。Ego 路径设 bottom_center=True：先 \(z\leftarrow z+h/2\) 抬到体心再采样， 使三层高度覆盖 车底～车顶（原先相对车底采样会采到地下、采不到车顶，易被地面点误挡 → 假 \(V=0\)）。 UAV 路径则先几何中心化再 warp 到 UAV 系。

缓冲经 visibility_fn=_ego_vis（ego 深度图）；池 ATTACK 用 UAV 深度图 + FOV。 无点云时回退 \(V=1\)（保守不标 ATTACK）。

6.2 判决

  • \(\mathcal{P} \ge \theta_{\mathrm{confirm}}\) → CONFIRM，输出并可入池
  • \(\mathcal{P} \le \theta_{\mathrm{reject}}\) → REJECT
  • 年龄 \(\ge T_{\mathrm{timeout}}\) 且 \(\mathcal{P}\) 仍不高 → TIMEOUT

\(\theta_{\mathrm{confirm}}\)（0.7，今日由 0.9 下调）· \(\theta_{\mathrm{reject}}\)（0.1）· \(T_{\mathrm{timeout}}\)（10） ablation — 主消融轴：偏 CONFIRM 提召回 vs 偏 REJECT 降幽灵。0.9 时 GT 命中 watch 的 lifetime max \(\mathcal{P}\) 多 < 0.65，几乎不 confirm。

7. 每帧流程

1. 三源检测；算 C、Q 2. 匈牙利关联 → D_ego, D_uav, D_init 3. 门控：Certain / Ambiguous(Dual) / Tentative 4. 信任池：UPDATE / BIRTH / HOLD；全 miss + UAV 可见 → ATTACK coast 5. Tentative 缓冲：Ego 证据更新；CONFIRM → Ŷ；缓冲 ATTACK 只打标 6. 接受集 = pool ∪ Certain ∪ CONFIRM ∪ 池 ATTACK coast

10.1 可见性 \(V\)（最大改动）

  • 问题：旧 box-ray 未传入 occluders → 日志里大量 \(V=1\)；与真实遮挡无关。
  • 改为：ego / UAV 点云 build_polar_depth + visibility_ratio_lidar；缓冲 visibility_fn 接 ego 深度；池 ATTACK 接 UAV LOS。
